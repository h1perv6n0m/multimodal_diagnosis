# Мультимодальная классификация новообразований кожи
Дипломная работа: разработка и сравнение классификаторов для диагностики новообразований кожи на основе рамановской спектроскопии и дерматоскопических изображений с использованием глубокого обучения, включая Vision Transformer (ViT).

## О проекте
Работа посвящена бинарной классификации новообразований кожи (злокачественные vs доброкачественные) с использованием двух модальностей:

* Рамановские спектры (одномерный сигнал)

* Дерматоскопические изображения (двумерные снимки)

## Сравниваются три подхода:

1. Классификация только по спектрам

2. Классификация только по изображениям

3. Совместный анализ спектров и изображений (мультимодальность)

Для каждой модальности сравниваются свёрточные нейронные сети (CNN) и трансформеры (ViT).

## Цель работы
Разработать и сравнить несколько классификаторов для бинарной задачи диагностики новообразований кожи, включая мультимодальные архитектуры, объединяющие спектральные и визуальные данные.

## Задачи
1. Подготовка и предобработка данных (спектры и изображения)

2. Построение одномодальных классификаторов (CNN и трансформеры)

3. Построение мультимодальных моделей (конкатенация признаков, объединение предсказаний, кросс-внимание)

4. Сравнение архитектур и анализ вклада каждой модальности

5. Визуализация областей внимания моделей

6. Программная реализация комплекса с графическим интерфейсом

## Структура проекта
* data/ - данные
  * spectra/ - исходные рамановские спектры (xlsx)
  * images/ - дерматоскопические изображения
  * processed/ - предобработанные данные
* src/ - исходный код
  * preprocessing/ - предобработка спектров и изображений
  * models/ - архитектуры моделей (CNN, ViT, мультимодальные)
  * training/ - скрипты обучения
  * evaluation/ - метрики, оценка моделей
  * visualization/ - визуализация внимания и результатов
* experiments/ - результаты экспериментов
  * plots/ - графики (ROC-кривые, матрицы ошибок, кривые обучения)
  * metrics/ - метрики
  * checkpoints/ - веса обученных моделей
  * logs/ - логи обучения
* notebooks/ - Jupyter-ноутбуки для исследований
* scripts/ - вспомогательные скрипты
* tests/ - тесты

## Данные
Датасет предоставлен онкоцентром. Содержит:

* Рамановские спектры новообразований кожи (диапазон 1100–1850 см⁻¹)

* Дерматоскопические изображения новообразований

* Метаданные: идентификатор пациента, тип образца (кожа/опухоль), класс (доброкачественная/злокачественная), подтип опухоли

## Технологии
* Python 3.10+

* PyTorch — обучение нейросетей

* Transformers (HuggingFace) — предобученные трансформеры

* timm — предобученные CNN и ViT

* scikit-learn — классические методы (PLS-DA), метрики, валидация

* pandas, numpy — работа с данными

* matplotlib, seaborn — визуализация

* PyQt6 — графический интерфейс

* SQLite — хранение данных

* PyInstaller — упаковка в исполняемый файл

## Установка

2. Создать виртуальное окружение

3. Активировать окружение

## Метрики оценки
* Accuracy

* F1-score (macro, weighted)

* AUC-ROC

* Чувствительность и специфичность

* Матрица ошибок

* ROC-кривые

* Фиксированное разделение train/test

* Кросс-валидация на тренировочной выборке

* Группировка по идентификатору пациента (образцы одного пациента не попадают одновременно в train и test)
