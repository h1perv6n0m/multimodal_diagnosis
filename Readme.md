# Мультимодальная классификация новообразований кожи

Дипломная работа: разработка и сравнение классификаторов для диагностики новообразований кожи на основе рамановской спектроскопии и дерматоскопических изображений с использованием глубокого обучения, включая Vision Transformer (ViT).

## О проекте

Работа посвящена бинарной классификации новообразований кожи с использованием двух модальностей:

* Рамановские спектры (одномерный сигнал)
* Дерматоскопические изображения (двумерные снимки)

Рассматриваются две постановки задачи:

1. Malignant vs benign — злокачественные против доброкачественных
2. Melanoma vs (nevus + seborrheic keratosis) — меланома против невуса и себорейного кератоза

Для каждой задачи сравниваются три подхода:

1. Классификация только по спектрам
2. Классификация только по изображениям
3. Совместный анализ спектров и изображений (мультимодальность)

Внутри каждой модальности сравниваются свёрточные нейронные сети (CNN) и трансформеры (ViT).

## Цель работы

Разработать и сравнить несколько классификаторов для бинарной задачи диагностики новообразований кожи, включая мультимодальные архитектуры, объединяющие спектральные и визуальные данные.

## Задачи

1. Подготовка и предобработка данных (спектры и изображения)
2. Построение одномодальных классификаторов (CNN и трансформеры)
3. Построение мультимодальных моделей (конкатенация признаков, объединение предсказаний, кросс-внимание)
4. Сравнение архитектур и анализ вклада каждой модальности
5. Визуализация областей внимания моделей

## Данные

Датасет предоставлен онкоцентром. Содержит:

* Рамановские спектры новообразований кожи (918 спектральных отсчётов, диапазон 284.89–3257.63 см⁻¹)
* Дерматоскопические изображения новообразований (формат TIFF, несколько режимов съёмки)
* Метаданные: идентификатор пациента, тип образца (кожа/опухоль), класс (доброкачественная/злокачественная), подтип опухоли

### Характеристики спектрального датасета

* Всего образцов: 1168
* Уникальных пациентов: 622
* Распределение по классам: skin — 609, benign — 278, malignant — 183, предрак — 18, прочее — 4
* Пропусков в спектрах: 0

### Характеристики датасета изображений

* Изображения хранятся в папках по классам: BCC, DF, HE, MM, NE, PP, SCC, SK
* Внутри каждого класса — папки с ID пациентов, совпадающие с ID в спектрах
* В каждой папке ID: 2–4 TIFF-файла (обычный и поляризованный свет) и папка `colored` с псевдоцветными вариантами

## Запуск

Скрипты предобработки запускаются из корня проекта:

* `python src/preprocessing/load_spectra.py` — загрузка xlsx и сохранение в CSV
* `python src/preprocessing/dataset_description.py` — описание датасета
* `python src/preprocessing/explore_spectra.py` — построение графиков спектров
* `python src/preprocessing/prepare_images.py` — предобработка изображений
* `python src/preprocessing/filter_spectra.py` — фильтрация и формирование датасетов по задачам
